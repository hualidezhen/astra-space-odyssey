# ASTRA · 星海远征

一个可玩的 WebGL 3D 太空探索原型。奥德赛空间站通过程序化几何建模，包含 8 个可独立分离与复原的功能模块。所有行星均为实际三维球体，可在周边空间自由驾驶与观察。

## 打开

- 离线版：用 Chrome 或 Edge 打开 `ASTRA-星海远征.html`，无需安装或启动服务器。
- 源码：在此文件夹运行 `python -m http.server 4173 --directory dist`，再打开 `http://localhost:4173`。
- 浏览器需要开启 WebGL / 硬件加速。

## 操作

- 观察：拖动旋转，滚轮缩放。点击空间站实体或右侧模块列表，可独立分离 / 复原模块。
- 拆解：右侧开关或滑杆控制整站爆炸视图；重置按钮恢复全部结构与观察位置。
- 飞行：顶部“自由飞行”或左侧“启航”。W / S 前进后退，A / D 左右转向，↑ / ↓ 俯仰，空格 / C 上升下降，Shift 加速。拖动画面也可转向。
- 跃迁：底部导航可前往八大行星与空间站，飞行模式中仍可跃迁。
- 扫描：在行星附近按 E 或点击扫描按钮。收集八大行星记录，进度自动保存到当前浏览器。
- H：隐藏 / 恢复界面，进入电影视图。Esc 也可恢复。
- 顶部提供环境音开关、全屏与完整操作指南。窄屏提供触控方向键。

## 内容与范围

- 空间站：指挥塔、生态环、连接桥、太阳能阵列、停泊港、聚变核心、实验舱、通信阵列。
- 场景：太阳、八大行星、月球、地球表面与云层、土星环、星海背景。
- 第三人称探索飞船、推进尾焰、平滑跟随镜头、跃迁过渡、行星防撞、扫描收集。
- 采用艺术化尺寸与距离。提供行星周边太空探索；提供独立的空间站内部舱室。没有行星表面着陆、地面行走或战斗。
- 这是浏览器实时程序化模型，不包含独立 Blender / CAD 资产。

## 写实画面升级

- 重新建模的双层承重环、带蒙皮的压力舱、交叉桁架、管线、散热片、天线支架和泊位设施。
- 重做的探索飞船舰体、座舱玻璃与框架、机翼蒙皮、推进器喷口及透明尾焰。
- Earth 8k 日景、独立夜景灯光和地形法线，真实行星纹理与透明土星环。
- 方向光阴影、金属反射、HDR 渲染与克制的高光辉光。

## 六步太阳系任务线

1. 进入舱内，走到导航指挥台，按 E 完成校准。
2. 前往地球并扫描。
3. 扫描火星，在档案展厅对照地貌参考图，点选水手峡谷。可以暂停自转后辨认，方向键或拖动可改变视角。
4. 第三人称驾驶探索者号在木星附近推进累计 4 秒，并扫描木星。W 推进，A/D 转向；防撞系统触发后可转向离开地表。
5. 扫描土星，进入环面摄影航线，调整到 15° 至 35° 的环面仰角，拍摄并存档。
6. 跃迁返航，在泊位 01 完成对接，经气闸前往舱内指挥台交付远征数据，获得「星海领航员」徽章。

任务卡提供下一步导航，支持折叠。完整航线可查看所有阶段；重新开始任务需要在航线弹窗中确认，不清除已有扫描与档案。每步只接受当前阶段的有效操作，已有扫描可再次确认来完成新任务。三类进度独立保存在浏览器中，离线版、在线版与不同浏览器之间不会自动同步。

## 空间站内部第一人称漫游

- 顶部「舱内漫游」进入独立舱内场景；包含中央走廊、导航指挥区与观景窗、行星研究室、船员生活舱和气闸。
- WASD 行走，Shift 快走，拖动或方向键环顾，E 与附近终端交互。可选鼠标锁定，Esc 释放；未允许鼠标锁定时仍可拖动操作。
- 小地图显示所在区域，四个导览按钮引导角色实际走向终端；按移动键可随时接管。墙壁和控制台设有碰撞边界。
- 导航台负责校准 / 交付，研究室打开行星档案，生活舱显示船员日志，气闸返回舱外。移动端提供触控方向键与交互按钮。
- 舱内采用虚构人工重力与艺术化空间结构，不是对真实航天舱室的工程复原。

## 行星特写档案展厅

- 顶部「行星档案」或研究室终端进入。八大行星采用独立特写视角，可旋转、缩放、暂停自转与复位。
- 「概览 / 观测细节 / 探索记录」展示行星资料、本机扫描状态和档案记录日期；「驾驶飞船前往」切回第三人称并跃迁。
- 行星文字与近似数值参考 NASA Science，各行星资料页直接列于展厅。影像纹理来源与署名仍见纹理目录。模型距离、比例、光照与部分纹理色彩经过展示用途调整。

## 飞船、舱内和行星精细化升级

- 飞船增加座舱内构、玻璃罩与框架、分瓣喷口、姿态控制喷嘴、舷梯和前向捕获探头。尾焰随推进状态变化。
- 停泊港增加机械臂、进近灯和锁环动画。点击「泊位 01 · 开始对接」，W/S 进退、A/D 横移、方向键上下调整高度，姿态自动保持对准。对准并松开推进后锁定，也可使用自动靠泊。进入气闸后可从舷窗看见同款探索者号。
- 模块接合处增加法兰、紧固件与连接结构，拆解后显露。舱内增加压力舱框架、设备台、开放式软包卧铺和实时任务屏，指挥屏随六步任务推进更新。
- 地球海面反光、云层相对移动和云影、昼夜灯光及晨昏大气散射共同显示。土星包含环影投射、行星投向环面的阴影与薄冰环的背光散射。
- 土星摄影在渲染完成后截取实际画面，照片保存在当前浏览器，显示在土星档案和舱内研究屏。页面重新打开后仍可查看最近一次照片。
- 原有任务进度继续读取。新增靠泊和摄影操作均提供屏幕按钮，窄屏额外提供触控操作。

## 验证

`node tests/mission.test.mjs` 验证任务顺序、错误事件不推进、部分进度恢复、返航交付条件与驾驶累计计时边界。
`node export.cjs` 生成包含三种体验与全部纹理的单文件离线版。
